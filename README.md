# Hookmatic

> **Content script inspiration** — AI-powered hook & script generator for TikTok creators in the Fashion & Sport niche.

Hookmatic helps you stop staring at a blank screen. Fill in your niche, audience, and tone — and get ready-to-use hook scripts, video outlines, CTAs, and hashtags generated by Gemini AI in seconds.

---

## Features

- 🎬 Generate 3 hook variations per request
- ⚡ **Singkat** (15–30s) or **Detail** (45–90s) format output
- 👟 Built for Fashion & Sport niches (Athleisure, Activewear, Sneakers, Streetwear, Outdoor)
- 🎯 Optional product title & description for sharper, more targeted hooks
- 📋 One-click copy to clipboard per hook card
- 🔒 API key stays secure — never exposed to the browser

---

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | React 19 + Vite + TypeScript |

| AI | Google Gemini (`gemini-3.6-flash`) via `@google/genai` |

## Getting Started

### Prerequisites

- [Node.js 22+](https://nodejs.org/)
- [pnpm](https://pnpm.io/installation) (`npm install -g pnpm`)
- A [Gemini API key](https://aistudio.google.com/app/apikey)

### 1. Clone & Install

```bash
git clone https://github.com/your-username/hookmatic.git
cd hookmatic
pnpm install
```

### 2. Set up environment

Create a `.env` file inside `apps/api/`:

```bash
# apps/api/.env
GEMINI_API_KEY=your_api_key_here
```

### 3. Run development servers

```bash
pnpm run start
```

This starts both servers concurrently via Turborepo:

- 🌐 **Frontend** → [http://localhost:5173](http://localhost:5173)
- ⚙️ **API** → [http://localhost:3000](http://localhost:3000)

## API

### `POST /v1/generate`

```json
{
  "niche": "Sneakers / Footwear",
  "audience": "Runner",
  "tone": "Contrarian",
  "format": "Singkat",
  "productTitle": "Nike Air Zoom Pegasus 41",
  "productDescription": "Daily trainer with ReactX foam, lightweight, available in 3 colorways.",
  "count": 3
}
```

**Response:**
```json
{
  "hooks": [
    {
      "hookTitle": "...",
      "hookScript": "...",
      "bodyBeat": "...",
      "cta": "...",
      "hashtags": ["#sneakers", "..."],
      "estimatedSeconds": 30,
      "platformTips": "..."
    }
  ]
}
```

### `GET /health`

Returns `OK` — for uptime monitoring.
